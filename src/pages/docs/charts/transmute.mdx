# Transmute

[Official upstream repository](https://github.com/transmute-app/transmute).

Production-ready Helm chart for Transmute, a self-hosted audio and video transcoding and compression service utilizing FFmpeg, Libvips, and hardware acceleration.

## Features

- Upstream official image .
- Non-root UID/GID 1000, read-only root options, dropped capabilities, RuntimeDefault seccomp.
- External Secrets Operator (ESO) integration with inline credential fallback.
- Gateway API () and standard Kubernetes Ingress support.
- Native OpenID Connect (OIDC) Single Sign-On parameters.
- Persistent queue and storage volume management.
