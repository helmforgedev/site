# Qdrant

Deploy [Qdrant](https://github.com/qdrant/qdrant) on Kubernetes as a vector database for semantic search, RAG applications, recommendations, and AI workloads.

## Overview

The HelmForge Qdrant chart uses the official `docker.io/qdrant/qdrant` image and defaults to a single persistent StatefulSet. It exposes the REST API on port `6333`, gRPC on `6334`, and the peer port on `6335`.

## Installation

```bash
helm repo add helmforge https://repo.helmforge.dev
helm repo update
helm install qdrant helmforge/qdrant
```

OCI install:

```bash
helm install qdrant oci://ghcr.io/helmforgedev/helm/qdrant
```

## Basic Values

```yaml
persistence:
  enabled: true
  size: 10Gi

service:
  type: ClusterIP
  port: 6333

ingress:
  enabled: true
  ingressClassName: traefik
  hosts:
    - host: qdrant.example.com
      paths:
        - path: /
          pathType: Prefix
```

## Operational Notes

- Data is stored at `/qdrant/storage` on a persistent volume.
- Use `resources` requests and limits for production workloads with large collections.
- Keep the peer port internal unless you intentionally build a multi-node topology.
- The chart includes Gateway API and dual-stack Service controls for clusters that use those networking models.
